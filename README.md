# WGU Capstone Mobile Application Using C Sharp .NET MAUI

## Description
A cross-platform (.NET MAUI) mobile application that helps students track their academic progress and manage their terms, courses, and assessments. Students can customize their academic information, view instructor information, and manage notifications for all important dates. They can check their overall progress and easily search for courses.
